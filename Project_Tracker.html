⚙ Setup — Store Data in Google Sheets

Status: not configured. Data is currently saved only in this browser.
One-time Google Sheet setup (5 min):
  1. Create a Google Sheet, e.g. Project Tracker.
  2. In the Sheet menu: Extensions ▸ Apps Script.
  3. Delete the sample code, paste the Code.gs from the project-tracker-apps-script folder (in your repo), then Save.
  4. Click Deploy ▸ New deployment ▸ Select type: Web app.
  5. Set Execute as: Me and Who has access: Anyone. Deploy and authorize.
  6. Copy the Web app URL (ends with /exec) and paste it above.
  7. Click Test Connection → then Save to Sheet. A Projects tab is created automatically, and auto-save / auto-load become active.
GitHub Pages: push this HTML file (rename to index.html or place in a folder) and the Apps Script file to your repo, enable Pages for the branch, and open the published URL. The Sheet URL is stored per-browser, so enter it once on each device.
Reads use JSONP · writes use Apps Script POST. No server required.
